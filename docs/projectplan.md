# Scander Project Plan


# Team Division


## Member 1 — Customer Ordering System


Responsibilities:

Frontend:

- Customer Web Interface


Backend:

- Table Session Module
- Order Module


Features:

- QR code access
- Digital menu viewing
- Shopping cart
- Order creation
- Order tracking



---

## Member 2 — Kitchen Operation System


Responsibilities:

Frontend:

- Kitchen Dashboard


Backend:

- Authentication Module
- Order Status Management


Features:

- Staff login
- View incoming orders
- Accept orders
- Update food preparation status
- Order history



---

## Member 3 — Admin and Payment System


Responsibilities:

Frontend:

- Admin Dashboard


Backend:

- Menu Module
- Payment Module


Features:

- Manage categories
- Manage menu items
- Manage table QR codes
- Payment processing
- Receipt generation
- Reports
